# Arizen CMS — guide for the website team

Sign in at **`/admin`** with the email and password an administrator gave you.

## Roles

| | Administrator | Editor |
|---|---|---|
| Products, categories, pages, media, inquiries | ✔ | ✔ |
| Delete products, categories, images, inquiries | ✔ | — |
| Change inquiry notification recipients | ✔ | — |
| Add or remove users, reset passwords | ✔ | — |

Signing out signs you out on every device. Accounts are locked for 15 minutes after repeated wrong passwords.

## Dashboard
Totals for products, categories and inquiries, the latest inquiries, and recent edits. The
**New inquiries** tile turns cyan when something is waiting for a first response.

## Inquiries
- Search by name, company, email or phone; filter by status, product and date.
- Open an inquiry to see the requirement, contact details and activity.
- **Status**: New → Contacted → In Discussion → Quotation Sent → Converted / Closed. Every change is logged.
- **Notes** are internal and never shown to the visitor.
- **Export CSV** downloads the current filtered list (opens in Excel).

## Products
- **New product** → fill in name and code (the web address is created from the name) → **Create product**.
- Turn **Published** on to show it on the website; drafts are private.
- **Technical specifications**: one row per property: value, unit and test method. Enter only confirmed values.
  If there are no rows, the website shows the specifications note and a "Request data sheet" button.
- **Available grades** and **Applications** appear as their own sections.
- **Related products**: tick up to a few; if none are ticked, products from the same category are shown.
- **Search engines & sharing**: the preview shows how the page will look in Google results.

## Categories
Group products into the filter tabs on the Products page. Use the arrows to set the order.
A category cannot be deleted while it still contains products.

## Pages
Every page's text and images, plus the **Navigation** menu and the **Footer**.
- Empty fields show as "To be provided by Arizen" on the site until filled.
- Image fields: **Choose image** opens the media library; add **alt text** describing the image.
- **Conceptual illustration** switches: keep them on for illustrations, turn them off when you
  replace an image with a real photograph of Arizen's premises.
- **Quality → Certifications**: only entries marked **Verified** appear on the website.
- Saved changes are live within about a minute.

## Media library
Drag images in (JPEG, PNG, WebP or AVIF, up to 10 MB). Each upload is resized, converted to
WebP and AVIF and stripped of location data. Before deleting, the library shows where an image
is used.

## Settings
Company name, official logo, address, email, phone, WhatsApp, business hours, map location,
social links, inquiry notification recipients (administrators), public website address,
default search title/description/sharing image, and the **placeholders** switch for launch.

## Good practice
- Write alt text for every image (accessibility and SEO).
- Keep meta titles under 60 characters and descriptions around 150.
- Never publish specifications, certifications or claims that Arizen cannot evidence.
